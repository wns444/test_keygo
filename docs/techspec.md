# Тестовое задание

## Задача

Есть сервис трекер-задач. Нужно доработать флоу:

- Если по бронированию возникла проблема, сотрудник создаёт internal task.
- Задача должна появиться в списке, корректно менять статус, логироваться и не дублироваться.

Предлагается с нуля написать небольшое веб-приложение для демонстрации только этой доработки.

### Backend API

Реализовать:

- Сущность `InternalTask`
- Эндпойнты получения / создания / изменения статуса задач

### Frontend

Сделать страницу:
`/bookings/[booking_id]`

На странице блок Internal Tasks:

- список задач;
- форма создания задачи;
- смена статуса;

UI можно простой. Красота не важна. Важна аккуратная работа.

### Tests

Минимум покрыть:

- создание задачи;
- запрет дубля;
- смену статуса;
- обработку ошибки API.

Плюсом:

- тест frontend-компонента;
- тест на валидацию входных данных.

### Logs / Monitoring / Grafana / Sentry

В README.md описать:

- какие события логировать;
- какие ошибки отправлять в Sentry;
- какие метрики вывести в Grafana;
- какой алерт настроить.

Пример метрик в Grafana: Internal_task_active_count – Количество активных задач
Пример алерта: Если internal_task_create_failed_total растёт быстрее N ошибок за 10 минут — уведомить Tech Ops.

## Стек

Обязательно:

- Backend: Python + FastAPI + Pydantic + Alembic + SQLAlchemy
- Frontend: React + Next.js
- Tests: pytest или аналог
- БД: в KeyGo используется MongoDB; в тестовом можно использовать любое удобное для того чтобы быстро показать решение
- Grafana / Sentry:
-- настраивать не нужно;
-- нужно только описать, какие логи, метрики и алерты вы бы добавили.

## Формат сдачи

Только GitHub-репозиторий.

В репозитории должно быть:

- /backend
- /frontend
- README.md

В README.md обязательно:

- как запустить backend;
- как запустить frontend;
- как запустить тесты;
- что реализовано;
- как бы подключили Grafana / Sentry.

Ожидаемое время выполнения: 3–4 часа. Не нужно делать большой production-ready продукт. Нужно показать инженерный подход: аккуратность, тесты, обработку ошибок, читаемый код.
